# Finance
Три вкладки:

 1. Депозит — вводиш суму, дату відкриття, дату зняття, ставку. Показує скільки днів, скільки відсотків, скільки на руки; графік росту; таблицю «а якщо забрати на 7/30 днів раніше або пізніше»; три методи підрахунку днів; вартість одного дня вкладу.
 2. Вексель — номінал, дата обліку, дата погашення, облікова ставка. Показує скільки утримає банк (дисконт) і скільки отримаєш; чим ближче до погашення обліковуєш, тим більше на руки.
 3. Аналіз ставок — річне порівняння математичного і банківського дисконтування, дисконтування проти накопичення (обернені процеси), критична умова і еквівалентні ставки.

ФОРМУЛИ

Прості відсотки (нарощення):
S = P(1 + n·i) — нарощена сума за n років
I = n·P·i — сума відсотків
(P — початкова сума, i — річна ставка, n — роки, S — нарощена сума, I — відсотки)

Нарощення за реальними днями (депозит):
S = P(1 + (t/K)·i) — сума за t днів
I = S − P — відсотки
за день = P·i/K — вартість одного дня вкладу
(t — днів вкладу, K — база року)

Методи підрахунку днів:
365/365 (точний) — t точні дні, K = 365 (або 366 у високосний)
365/360 (банківський) — t точні дні, K = 360
360/360 (наближений) — t наближені дні, K = 360
Точні дні = календарна різниця між датами.
Наближені дні (30/360): t = (рік2−рік1)·360 + (міс2−міс1)·30 + (день2−день1)

Математичне дисконтування:
P = S/(1 + n·i) — теперішня вартість майбутньої суми S
D = S − P — дисконт

Банківський облік (вексель):
P = S(1 − n·d) — за роками
P = S(1 − (t/K)·d) — за днями (для векселів K = 360)
D = S − P — дисконт, який утримує банк
(d — річна облікова ставка)

Критична умова банківського обліку:
1 − n·d > 0
Якщо не виконується — теперішня сума від'ємна, операція неможлива (критична точка). Калькулятор попереджає.

Еквівалентні ставки (дають однакову теперішню вартість):
i = d/(1 − n·d) — облікова d у просту i
d = i/(1 + n·i) — проста i в облікову d
